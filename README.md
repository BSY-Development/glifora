# Glifora

Jogo web open source (PWA, mobile-first) para aprender idiomas conversando com NPCs numa vila de fantasia em pixel art. Funciona sem cadastro e sem IA; com a sua própria key de IA (BYOK), a conversa fica livre. A key vai direto do navegador ao provedor e nunca passa por servidor do projeto.

**Em construção:** fase 0 (arquitetura).
